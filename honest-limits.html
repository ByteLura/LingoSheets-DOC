Honest Limits: What v1 Is Not

Honest limits, printed on purpose. Everything here is a decision, not an oversight, and none of it is hidden in fine print anywhere else. This page expands the limits page shipped inside the package and adds nothing beyond it and the product specification.

  • No live sync of any kind. No hosted sheets, no cloud fetch, no auto-refresh from a URL, no accounts, no tokens, and no connection to any hosted spreadsheet service. Spreadsheets are local files, and import is a deliberate click on one of them. This is the product's founding decision: a localization pipeline that cannot stop working because a service did.
  • No spreadsheet loading in player builds. Sheets are an Editor pipeline. Your game ships the imported string table asset — no file parsing and no file access at runtime, and tables ship as assets rather than being loaded from sheets.
  • No XLSX writing. Export is CSV/TSV. Every common spreadsheet application opens them, and translators can return either CSV or XLSX — both import.
  • XLSX import reads the first worksheet only. Formulas are never executed; a formula cell contributes its cached string value or is skipped with a warning. Number and date handling follows the Sheet Format page.
  • Not a full bidirectional engine. Right-to-left support means: right-to-left language detection, a compact Arabic shaper scoped to single-line UI text and to the shipped samples, and direction and alignment handling that the components apply. It is not a complete UAX#9 implementation. Long multi-paragraph mixed-direction documents are the platform text stack's job, not this package's.
  • No shaping for scripts beyond Arabic. Hebrew-class scripts receive detection plus direction and alignment handling. Indic and Thai shaping belong to the platform text stack.
  • No plural or gender rules. There is no ICU MessageFormat engine. Placeholders are {0}-style and {name}-style replacement, which covers the large majority of game strings. Grammatically branching sentences are yours to key separately (for example shop.offer.one and shop.offer.many).
  • No machine translation, no translation memory, and no glossary checks. This package moves strings between your sheet and your game and shows you what is missing. The words themselves are your translators' craft.
  • No bundle delivery. Tables are plain assets in the build. There is no Addressables or asset-bundle packaging of tables in v1.
  • Font fallback is per language, per component, plus whatever fallback chain your TextMeshPro font assets themselves define. There is no per-character font substitution engine in this package.
  • Import and export are deliberate, separate actions. Nothing synchronises on its own, in either direction, at any time.
  • No other ByteLura product is required. The package installs and works on its own; its only declared dependencies are uGUI and TextMeshPro.
