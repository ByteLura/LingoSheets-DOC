API Summary

A compact summary of the public surface. This page summarises the API Reference shipped inside the package; it adds no calls that page does not list. Namespaces: ByteLura.LingoSheets for runtime, ByteLura.LingoSheets.Editor for Editor tools.

Localization (static facade)

  • Initialize(LingoSettings) — one-time setup. Skippable when Run Setup was used, because settings then auto-load from Resources; explicit initialisation always wins.
  • EnsureInitialized() — loads settings from Resources when present.
  • CurrentLanguage — the active LanguageCode.
  • SetLanguage(LanguageCode) — switches language; raises LanguageChanged once per actual change.
  • LanguageChanged event — carries the new LanguageCode; the current language is already updated when handlers run.
  • Get(key) — resolved string for the current language, through the fallback chain.
  • Get(key, params object[]) — indexed placeholder formatting ({0}, {1}), invariant formatting.
  • GetNamed(key, IReadOnlyDictionary<string, string>) — named placeholder replacement ({playerName}).
  • TryGet(key, out string) and HasKey(key) — non-committal lookups.
  • MissingLog — the in-memory list of fallback records: key, requested language, resolved-from language, hit count.
  • MissingKeyFound event — raised for buyer tooling when a lookup resolves by fallback.
  • ClearMissingLog() — empties the log. The log also clears on initialisation.
  • Settings and IsInitialized — the active settings asset and whether one is loaded.

Behaviour contract: a lookup never returns null, and lookups are written so they do not throw into the game loop. A malformed placeholder returns the raw text and counts a defect. An unknown named placeholder is left in place and counted.

LanguageCode

  • Construction from a string, with normalisation to en / pt-BR form (lower-case language, title-case region; underscores, case, and surrounding spaces are forgiven).
  • BaseLanguage — the language without its region (pt for pt-BR).
  • FromSystemLanguage(...) and the matching conversion back to SystemLanguage; unknown maps to the empty code.
  • DisplayName — a menu-ready name.
  • The empty code means no language and is valid wherever a code is accepted.

StringTable

  • The imported sheet as an asset: Entries, Languages (in column order), DefaultLanguage.
  • FindEntry(key), HasKey(key).
  • Direct edits are possible in the inspector; code can merge values through AddOrUpdateEntry.
  • Lookup construction keeps the last entry for a duplicated key and counts the duplicate in the table's build report.

LingoSettings

  • Table — the active string table.
  • DefaultLanguage.
  • FallBackToKey — whether the final fallback step returns the key itself (on) or an empty string (off).
  • PseudoLocalization — the layout stress-test toggle (Pseudo-Localization).
  • TmpFonts and GuiFonts — the per-language font maps; FindTmpFont(code) and FindGuiFont(code) answer lookups (Fonts and Fallback Chains).

Components

  • LocalizedTextMeshPro — binds a TMP_Text (UI or 3D) to a key.
  • LocalizedText — binds a uGUI Text label to a key.
  • Shared behaviour: serialized key, optional inspector format arguments, refresh on enable and on language change, per-language font application, optional automatic alignment flip for right-to-left languages, Arabic shaping on output.
  • LanguageDropdownTMP and LanguageDropdown — language pickers listing the table's languages by display name; selection switches the language, and an external switch moves the picker without a second language-change event.

PseudoLocalization

  • PseudoLocalization.Apply(text) — brackets the text, doubles vowels, and pads length by roughly a third (about 35 percent). Deterministic. Placeholders pass through byte-identical. Null or empty input returns empty.

RtlSupport and ArabicShaper

  • RtlSupport.IsRightToLeft(code) — base-language detection for ar, he, fa, ur, ps, sd, ug, yi, dv, ckb.
  • RtlSupport.ContainsRtlCharacters(text) and ContainsArabicCharacters(text).
  • ArabicShaper.Shape(text) — logical-order Arabic to shaped, visually ordered form for single-line UI text, with lam-alef ligatures and diacritic marks kept attached (RTL and Arabic Shaping, scope on the Honest Limits page).

Editor tools (public)

  • StringTableImporter — sheet grid or file to table, with the plain-language import report (Import and Merge).
  • StringTableExporter — table to CSV/TSV, full or untranslated-only per language (Export and Missing Reports).
  • MissingTranslationReport — per-language missing counts, coverage percentages, and missing key lists (Export and Missing Reports).
  • LingoSheetsVersion.Version — the package version string, 1.0.0.
