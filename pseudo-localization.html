Pseudo-Localization

Purpose

Pseudo-localization stress-tests your interface before real translations arrive. Turn it on and every resolved string becomes visibly marked and noticeably longer, so labels that overflow, truncate, or clip show themselves while the fix is still cheap.

Turning it on

  • In the settings asset: the PseudoLocalization option.
  • In the home window: the toggle in the footer mirrors the same setting.

It applies to resolved strings at lookup time, so bound components and code lookups both show the transformed text. Turn it off and normal text returns; nothing in your table is changed by the transform.

The transform

For each resolved string, the transform:

  • Wraps the text in plain square brackets, so pseudo-localized screens are unmistakable at a glance.
  • Doubles every vowel.
  • Pads the end so the result is roughly a third longer than the input (about 35 percent).

Properties worth knowing:

  • Deterministic: the same input always produces the same output, so screenshots and comparisons stay stable.
  • Placeholders pass through unchanged. {0} and {playerName} stay byte-identical inside the transformed text, so formatting keeps working and placeholder handling can be exercised under pseudo-localization too.
  • Empty input produces empty output.

How to use it well

  1. Turn it on, press Play, and walk every screen.
  2. Note labels that clip, buttons that squeeze their text, and layouts with no room to grow. Real translations into many languages run longer than English source text; a layout that survives the padded transform has headroom.
  3. Check screens with dynamic values as well: because placeholders survive, score lines and named greetings still format correctly under the transform.
  4. Turn it off before judging translation coverage. The missing-translation report (Export and Missing Reports) reads the table, not the transform, but your eyes should judge real text, not padded text.

Pseudo-localization is a layout tool. It does not translate, approximate a real language, or stand in for reading the finished text in each shipping language.
