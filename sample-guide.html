Sample Guide: Hello World Tour

What the sample is

One greeting card, seven languages, and the whole product in miniature. The sample ships as the Hello World Tour sample in the package and is imported through the Package Manager. Its scripts use only the public runtime surface — the same calls and components your own project will use.

Run it

  1. Import the sample from the Package Manager (LingoSheets Pro, Samples, Hello World Tour, Import).
  2. Open Tools > ByteLura > LingoSheets Pro and click Run Setup if you have not already, then Open the Hello World Tour.
  3. Press Play. Use the on-screen buttons or the language dropdown to walk English, Spanish, German, French, Arabic, Hebrew, and Japanese.

What to look at

  • The big greeting is a TextMeshPro label and the line under it is a uGUI label. Both are bound components; no code switches their text.
  • Arabic shapes and right-aligns. Hebrew right-aligns. Switch back to English and layout and fonts return to their original state.
  • One line, "This line only exists in English", is translated nowhere else on purpose. In every other language it falls back to English, and the home window's Runtime missing keys block records the miss while you play. That is the fallback chain (Runtime Use) doing its documented job.
  • The tour's strings live in Data/hellotour.csv, next to the sample README. That sheet is the source of truth for the sample's own table.

The sample sheet, measured

  • 8 keys: tour.greeting, tour.welcome, tour.prompt, tour.language, tour.score, tour.thanks, tour.goodbye, tour.demo.fallback.
  • 7 language columns: en, es, de, fr, ar, he, ja — plus the key column and a comment column.
  • tour.score carries a {0} placeholder in every language, so formatting can be watched in each language.
  • tour.demo.fallback carries a value in English only. In the Missing translations block it shows as missing in the other 6 languages, by design.

The one-minute experiment

This is the workflow your own project will use, compressed into the sample:

  1. Stop Play. Open Data/hellotour.csv in your spreadsheet application.
  2. Change the Spanish greeting to anything you like. Save as CSV.
  3. In the LingoSheets Pro window, point Settings at the sample's setup, click Import sheet, and choose the file. The report tells you exactly what changed: 1 updated.
  4. Press Play and switch to Spanish. Your word is in the game.

Sheet, import, game — that round-trip is the entire product workflow.

Reading the sample code

The controller script drives the language walk and the dropdown through the public calls summarised on the API Summary page. The sample assembly references the Runtime assembly only, which is deliberate: if it resolves and reads well here, the same surface is what your project codes against.
